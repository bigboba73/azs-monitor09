# Мониторинг наличия топлива на АЗС ГПН (24/7)

Скрипт раз в 30 минут проверяет статус топлива на АЗС №143
(А113 Кострома-Иваново, 139 км) через сайт gpnbonus.ru.

При изменении статуса любого вида топлива шлёт **email** всем подписчикам.

Статусы: **В НАЛИЧИИ / В ПУТИ / НЕТ В НАЛИЧИИ**.

Работает на серверах GitHub (GitHub Actions) — компьютер можно выключать.

## Что нужно для работы

1. Почта-отправитель (можно Яндекс или Gmail) с «паролем для приложений».
2. Репозиторий на GitHub с этими файлами.
3. Список подписчиков в `recipients.txt`.

## Настройка за 10 минут

### 1. Почта-отправитель (Яндекс)

1. Заведите почту на Яндекс, например `azs-monitor@yandex.ru`.
2. Зайдите в настройки → «Безопасность» → «Пароли приложений» →
   «Создать пароль приложения», тип — «Почта».
3. Яндекс покажет пароль вида `xxxxxxxxxxxx` — сохраните его.

### 2. Заполните файлы

- `config.json` — в поле `sender` укажите ваш ящик-отправитель
  (например `azs-monitor@yandex.ru`).
- `recipients.txt` — впишите email получателей, по одному на строку
  (папа, родственники, ваш — в общем «To» письма). Строки с `#` игнорируются.

### 3. Создайте репозиторий на GitHub

1. На github.com нажмите New repository. Название любое, например `azs-monitor`.
   Обязательно **Public**, чтобы не упереться в лимит бесплатных минут
   (в Private лимит 2000 минут/мес, при проверке каждые 30 минут — как раз на грани).
   Не создавайте README при создании.
2. Загрузите файлы (в терминале, где лежит этот проект):

```bash
git init
git add .
git commit -m "Мониторинг АЗС"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/azs-monitor.git
git push -u origin main
```

### 4. Добавьте секреты (SMTP)

На GitHub в репозитории: **Settings → Secrets and variables → Actions → New repository secret**:

| Секрет          | Значение                          |
|-----------------|-----------------------------------|
| `SMTP_HOST`     | `smtp.yandex.ru`                  |
| `SMTP_PORT`     | `465`                             |
| `SMTP_USER`     | `azs-monitor@yandex.ru`           |
| `SMTP_PASSWORD` | пароль приложения из шага 1       |

Для Gmail: `SMTP_HOST=smtp.gmail.com`, пароль — пароль приложения Gmail.

### 5. Запустите вручную для проверки

Вкладка **Actions → Monitor AZS → Run workflow → кнопка**. Зайдите в запуск и
посмотрите, что шаги прошли зелёным, а в логе `Изменений нет` или `Отправлено письмо`.

Дальше всё работает само по расписанию (каждые 30 минут по Гринвичу).

## Как поменять частоту проверки

В файле `.github/workflows/monitor.yml` строка `cron: "*/30 * * * *"`.
Чем чаще, тем быстрее узнаете о бензине:
- каждые 15 минут: `*/15 * * * *`
- каждый час: `0 * * * *`

## Запуск на своём компьютере (не обязательно)

```bash
pip install -r requirements.txt
SMTP_HOST=smtp.yandex.ru SMTP_PORT=465 \
SMTP_USER=azs-monitor@yandex.ru SMTP_PASSWORD=пароль \
python monitor.py
```

Работает только пока компьютер включён — для 24/7 нужны GitHub Actions.

## Файлы

- `monitor.py` — сам скрипт
- `config.json` — настройки (АЗС, отправитель)
- `recipients.txt` — список подписчиков
- `state.json` — последний известный статус (не трогать руками)
- `.github/workflows/monitor.yml` — расписание на GitHub
